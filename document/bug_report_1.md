# バグ調査報告書

## 概要
ユーザーから報告された以下の2点の不具合について、原因調査および修正方針をまとめました。

1. **2周目以降のゲーム進行不能**: プレイ可能な状況でも「パス」しか選択できない。
2. **スマホレイアウト崩れ**: 3行目のカードが見切れている、カードが減っても表示がおかしい。

---

## 1. ゲーム進行不能（2周目以降）

### 現象
継続して2ゲーム目以降をプレイする際、自分にプレイ権がある（またはフィールドがクリアされるべき）状況であっても、フィールドのカードがクリアされず、結果として「パス」しか選択できなくなる（または非常に強いカードしか出せない）状態に陥る。

### 原因
`js/game_core.js` の `passAction` メソッドにおける**パス成立判定（場のクリア判定）のロジック不備**が原因です。

```javascript
// js/game_core.js : 512行目周辺
if (this.passCount >= 3) {
    // ... フィールドクリア処理
}
```

現在のコードでは、フィールドクリアの条件が「`passCount` が **3** に達した時」と固定されています。
しかし、2周目以降（あるいは1周目でも）、「あがり（Finish）」が出た場合、アクティブなプレイヤー人数が4人未満になります。

**例：1名があがって抜けた場合（残り3名）**
1. 自分の手番。カードを出す。
2. 次のプレイヤー（CPU1）：パス (`passCount` = 1)
3. 次のプレイヤー（CPU2）：パス (`passCount` = 2)
4. 次のプレイヤー（あがった人）：スキップされる
5. **自分の手番に戻る**

この時点で、全員がパスをしたため本来はフィールドがクリアされ、自分は好きなカードを出せるはずです。
しかし、コード上は `passCount` (2) < 3 であるため、フィールドがクリアされません。
その結果、自分が直前に出したカード（おそらく強いカード）が場に残ったままとなり、それよりも強いカードを出せない限り「パス」を強制される（あるいはルール上出せない）状態になります。
ユーザーが「パス」を選択することでようやく `passCount` が3になり、フィールドがクリアされます。

### 修正方針
パス判定の閾値を固定値「3」ではなく、「現在プレイ中の人数（あがっていない人数） - 1」動的に計算するように修正する必要があります。

**修正案のイメージ:**
```javascript
const activePlayerCount = this.players.filter(p => p.hand.length > 0).length;
if (this.passCount >= activePlayerCount - 1) {
    // フィールドクリア
}
```

## 2. スマホ実行時のレイアウト破綻

### 現象
スマートフォンなどの狭い画面でプレイした際、手札が3行に折り返され、以下の問題が発生している。
1. 第3行目のカードの下部（または全体）が画面外に見切れ、視認性が著しく悪い。
2. カード枚数が減っても、レイアウトの崩れ（見切れや不自然な空白）が継続する。

### 原因
CSSのFlexbox設定と、画面全体のコンテナ設定（`overflow: hidden`）の競合が原因です。

1. **カードの折り返し**: `.hand-container` に `flex-wrap: wrap` が設定されており、横幅が狭いスマホ画面ではカード（13枚）が3行に折り返されます。
2. **高さの超過**: 3行になると手札エリアの高さが大幅に増えます（約15rem以上）。メインコンテナ（`.game-board`）は `h-screen` かつ `overflow-hidden` で固定されており、中央のフィールドやCPUエリアの高さと合わせると画面の高さを超えてしまいます。
3. **クリッピング**: `overflow-hidden` のため、画面からはみ出した部分（手札の最下段など）が切り取られ、ユーザーから見えなくなっています。

「3行目基準のため〜」という指摘も、Flexboxの `align-content` や親要素の `justify-content` の兼ね合いで、カードが減ってもコンテナの高さが確保されたまま（あるいは他要素からの圧迫）で、常に表示領域の境界におかしな形で配置されている可能性があります。

### 修正方針
スマホ（モバイル）環境においては、**「カードを折り返さずに横スクロールで表示する」** 形式への変更を推奨します。これにより、行数が増えて画面を圧迫することを防ぎ、常に全てのカードを視認可能にします。

**修正案のイメージ (CSS):**

```css
/* モバイル向け調整 */
@media (max-width: 768px) {
    .hand-container {
        flex-wrap: nowrap;       /* 折り返し無効 */
        overflow-x: auto;        /* 横スクロール有効 */
        justify-content: flex-start; /* 左詰め（スクロールしやすいように） */
        padding-bottom: 10px;    /* スクロールバー等の余裕 */
        min-height: auto;        /* 高さを自動調整 */
    }
    
    /* スクロールバーを隠す場合（任意） */
    .hand-container::-webkit-scrollbar {
        height: 4px;
    }
}
```

また、2周目以降の「継続」タップ後も、このCSS変更だけで解消されるはずです。
